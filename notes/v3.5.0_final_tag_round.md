# AWI-ESM3 v3.5.0: what the final tag round needs

Written 2026-10-07, corrected the same evening after checking the existing tags (`notes/awiesm3_v3.5.0_component_tags.md`). Purpose: the CMIP7 spin-up is to run on `v3.5.0-cc` after one last update of the
release tags. A test spin-up runs on `develop-cc` first (`SPIN_cc_test1`, smoke test `TEST_ccspin_1y`).
This file lists what each component still needs before the tags can be moved.

## Configuration the spin-up uses

- Start: FESOM cold from PHC3, REcoM cold (GLODAP PI, WOA13/18, PISCES iron), OpenIFS from initial
  conditions, LPJ-GUESS from the offline spin-up
  `/albedo/scratch/projects/p_awiesm3_cmip7/jstreffi/runtime/lpjg-spinup/LPJG-SPINUP_2000Y_TCO95_CORE3_PICALforcing_ndep1850/`
  (state of year 3901).
- CO2 pre-industrial and concentration-driven; REcoM receives the OpenIFS mean sea-level pressure.
- Ocean: `cvmix_TKE` without IDEMIX; `K_GM_max` 2500 south / 1000 north with a 10 degree transition;
  time step 1800 s; `albsn` 0.82.
- Icebergs on: calving minus basal melt, start rate 1105 Gt/yr, mapper calving off for Antarctica.
- Sea-ice roughness entries in `NAMSURFTUNE` stay at their defaults.
- Length: only as long as the carbon fluxes need to meet the drift thresholds (the abyss warms at
  +12.5 mK per decade regardless of length, see `data/clim/deep_warming_where.txt`).
